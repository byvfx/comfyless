# Comfyless brand

Unplugged: a standalone Comfyless mark. No BYVFX lockup.

## Assets

| File | What it is |
|---|---|
| `docs/images/icon.svg` | App icon. Dark charcoal rounded tile, Warm Persimmon A2 mark. `viewBox="0 0 64 64"`, drawn at 400×400. Corners outside the rounded square are transparent. |
| `docs/images/icon.png` | 400×400 RGBA render of `icon.svg`. README logo and the Comfy Registry `Icon`. |
| `docs/images/icon-mark.svg` | Standalone A2 mark, `#F0784B`, no tile. |
| `docs/images/icon-mono.svg` | Same mark with `fill="currentColor"` and no background, for monochrome use. |
| `web/js/icon-mono.svg` | The same path filled black, masked by the sidebar icon so it inherits the ComfyUI icon color. |
| `docs/images/social-preview.svg` | Source art for the GitHub social card. |
| `docs/images/social-preview.png` | 1280×640 card. Upload this file in the repo settings. |

The A2 paths are the locked geometry: a sculpted cloud with a plug cut out of the bottom.

## Palette

| Token | Hex | Where to use it |
|---|---|---|
| Warm Persimmon | `#F0784B` | The mark and small accents. 6.25:1 on `#1B1918`, 6.04:1 on `#1A1D21`. Do not set body text in this color on a light surface (2.80:1 on white). |
| Warm Charcoal | `#1B1918` | Dark surfaces and the app tile. Tile border is `#2A2725`. On white it is 17.52:1, so it is also the ink on light surfaces. |
| Soft Cream | `#F6EEDD` | Text and highlights on charcoal (15.18:1). Not for text on white. |
| Light ink | `#1B1918` | Body text on light surfaces. |

Error states stay `#ef4444`. Persimmon is not an error color.

## Voice

Comfyless is a tool you use on your own. Write in plain second person. Do not say "we". "Modal" means the person's Modal account, not the product name.
